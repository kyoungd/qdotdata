# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

**IMPORTANT: Do not make code changes without user confirmation.**

## ⚠️ MOST IMPORTANT RULE

**Before implementing or altering code, always ask for confirmation. Never change code without explicit confirmation.**

- Show the plan first
- Wait for user approval
- Only then make changes

### Workflow: Errors
1. Find the cause
2. Show it to the user
3. Suggest a fix
4. Get agreement
5. Create a plan to fix
6. Get confirmation
7. Code the fix

### Workflow: Tasks
1. Suggest a design
2. Get agreement
3. Create an implementation plan
4. Get confirmation
5. Implement the plan

### Git Commits and Pushes
**Do not commit or push without explicit permission.** The user needs to test changes first before committing. Wait for the user to say "commit" or "push" before doing so.
